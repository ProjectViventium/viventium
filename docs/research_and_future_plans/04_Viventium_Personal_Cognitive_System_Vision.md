# Viventium Personal Cognitive System Vision

This proposal has been expanded and consolidated into the segregated
[`V0.5 Vision Package`](v0.5/README.md).

Use the V0.5 package as the single future-vision route for:

- the Life-centered cognitive architecture;
- Viventium Sources;
- conversation memory and Insights;
- seamless GlassHive mission context and return;
- cortices, Feelings, and Sleep Growth;
- LibreChat's continuing but non-exclusive role;
- the browser-editable architecture and Sources wireframe;
- the historical V0.5 `test-Life-v0.01/` prototype.

The smaller implemented LIFE bootstrap is intentionally owned outside the V0.5 proposal at
`templates/life-v0.01/`; installing that core folder does not activate the broader V0.5 thesis.

Current implemented product truth remains in `docs/requirements_and_learnings/`.

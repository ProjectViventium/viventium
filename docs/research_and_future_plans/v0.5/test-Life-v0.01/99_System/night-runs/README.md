# Private Night Run Receipts

Private, serializer-redacted manifests and terminal receipts for existing overnight jobs. Record
inventory coverage, changed sources, bounded deep-read scope, owner/run ID, outputs, source health,
failures, stale inputs, callbacks, validation result, and remaining work.

This is system state, not a human insight feed. Access is scoped; meaningful eligible outputs may be
projected into `Insights/`, and proactive Morning Brief delivery remains opt-in.

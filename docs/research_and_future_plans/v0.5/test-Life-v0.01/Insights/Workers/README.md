# Night Workers

One manifest per approved worker. Each manifest declares:

- stable worker ID and human title;
- purpose and non-goals;
- cadence and scheduler owner;
- executor/agent host;
- input inventory and permission scope;
- output schema and destination;
- memory-write mode;
- retention and surfacing policy;
- model/effort policy where required;
- QA owner and last accepted run.

Do not create a second scheduler or duplicate a current Background Cortex/Periphery function merely
to make this folder look complete.

# Communications

Source-linked communication views of email, chats, calls, meetings, social conversations, and voice
activity. Original messages remain authoritative in their source system. Transcript and ambient
evidence is canonical under `Memory/`; Communications contains only navigational views or indexes.

- `Listen_Only/` is a communication view over eligible `Memory/Ambient/` evidence.
- `Wing_Mode/` is a communication view over user-approved assist sessions and outcomes.
- `Transcripts/` is a communication index over canonical `Memory/Transcripts/` evidence.

These folders must not duplicate transcript text or establish competing authority.

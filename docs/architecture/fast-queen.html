Method and context size

Each normal cell has three samples. The full frame is about 200k characters: about 60k of application context plus unchanged selected history. These are measured sizes, not limits. No source was cut.

Reply timing is the first text delta of a natural check-in. It can begin with voice markup; first useful words and first audio were not separately timed. Flag timing is a complete yes/no decision on a substantial research and test request. The decision probe is separate from the natural reply. Actual work admission and result delivery are not included.

Cold Claude Code includes process startup. Warm Claude Code uses one retained native conversation after a separate seed. Other rows use fresh native threads or stateless Direct requests; provider caches can be warm. Shared-machine load, cache state, wrappers and tokenizers differ. This is not a controlled transport-only comparison.

A correct flag does not prove quality. Some outputs repeat old call details, ask needless questions or imply work has started. No route passes full user acceptance from these samples alone.

# Cognitive-system diagram assets

These are the approved diagrams for the [Viventium cognitive-system vision](../../cognitive-system.md).
The SVGs are the editable vector originals. The PNGs are matching high-resolution previews.
Light and dark versions have the same content and layout.

Keep these four files together when updating the diagram. Preserve readable text, visible
connections, the horizontal channel row, and the separate new-user journey. Check both themes
at normal reading size and at full resolution. Concept labels must not imply shipped support.

## Escaped Defects Found By Real Web QA

1. **Provider transfer gap.** GlassHive accepted Agent Builder function tools as ignored extras and
   returned only text. The provider now bridges structurally valid zero-input transfers through
   standard OpenAI `tools`/`tool_calls`; every current Main handoff uses shared-history zero-input
   transfer, while an unforced input-bearing legacy tool may coexist outside the bridge.
2. **Prompt-only handoff loop.** Main could repeatedly select Red Team. A generic completed-target
   receipt now removes that target for the same agent/user-turn family. New turns start fresh.
3. **Stop race.** Main's earlier child was terminal while Reality was active, so the first Stop did
   not fence Main and a hidden Main child completed afterward. Explicit family Stop now tombstones
   every participant base for the stopped turn under the start lock; request-only cancel stays
   non-poisoning.
4. **Unbounded native stall.** One Reality worker completed its searches but remained in native
   execution for roughly 13 minutes until the user pressed Stop. The post-review source fix adds a
   persisted, configurable, then-defaulted 180-second ingress-anchored foreground response budget for
   stream/nonstream requests,
   returns one retryable timeout, interrupts the exact native run outside the provider start lock,
   and fences late answer/tool output. Automated deadline/race/migration tests pass; the real-Web
   timeout and recovery rerun passed with a 30-second QA override, then the then-current 180-second default was
   restored and the next turn completed.
5. **Citation polish.** Consultant detail can expose opaque native reference markers even when the
   underlying source and final synthesis are valid. This remains a visible UX defect.
6. **Claude graph-schema mismatch.** The first real fallback rejected the canonical draft marker.
   Claude now receives the same strict envelope with only its unsupported top-level dialect marker
   removed; native initial/resume probes and the real Browser fallback passed.
7. **Deadline/Stop races.** Adversarial tests found late completion, queued-after-Stop execution,
   legacy-schema migration, stale sync, fallback-loser diagnostic corruption, a process-local Stop
   fence, and one-shot cancel delivery. Transactional claims, guarded sync, legacy rebuild/backfill,
   queued-run cancellation, then-current persisted 600-second family tombstones, and bounded acknowledged
   delivery now pass. Real Web confirmed that both participant receipts and the fence survive a
   provider restart; LibreChat cancellation still intentionally has no crash-durable outbox.
8. **Memory health is separate from context delivery.** The Main Agent received a bounded Immediate
   Access snapshot and used the synthetic My World evidence, but a later detached memory-writer run
   exhausted its provider allowance after retry. Deep Memory also hit its primary rate limit during
   the final Stop case and its fallback was correctly aborted by Stop. Memory writer/Dreaming
   reliability is therefore not accepted by this anti-sycophancy run.

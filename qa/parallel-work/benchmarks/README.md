  Claude Code identity and OAuth beta headers. Successful responses prove this existing path works

  was made. Both adaptive Low and off runs reported zero thinking tokens in this sample.

### Context and clocks

One frozen frame contains complete admitted application authority: identity/personality, relevant
memory and current Feelings, about **60k characters**. The full frame adds the unchanged selected
conversation, about **200k characters total**, before the distinct latest measurement request and
native wrappers. These are rounded measured sizes, not courier limits. No source was truncated.
The request explicitly supersedes historical accepted-turn markers for this probe only.

Natural reply is a short check-in, measured to the first text delta. A delta can begin with
inherited voice markup; first useful words and first audio were not separately timestamped. The adjacent negative control returns
one brief reply plus `handoff:false`. The positive case requests substantial self-hosted call
research and an isolated test, with `handoff:true`. Tools are disabled. Only completed output
establishes flag readiness; first JSON punctuation is not a ready decision. No work is actually
admitted, executed or delivered by these tests.

Three repetitions per normal cell; cold seed and failed controls are separate. Publish medians,
observed ranges and success/attempt counts. No p95 or universal fastest-model claim is supported.
Two initial Opus 5 setup completions are retained privately outside the 115-attempt matrix.
Native Codex confirms its selected model in configuration/catalog; it does not separately echo an
effective model on each returned turn. Other completed routes retain returned/init model evidence.
Provider tokenizers, wrappers, caches, output lengths and startup differ. Warm turns retain earlier
probe turns; cold/stateless trials replay a frozen frame. Some native Codex and warm Opus trials
shared laptop load. Context sizes ran in a fixed order, so latency differences cannot isolate a
causal context-size effect. Exact token counts need not match across providers.

### Quality is a separate gate

Strict JSON and yes/no checks pass in many cells, but do not prove the requested experience.
Private output inspection found stale call references, unnecessary questions, long acknowledgments
and phrases implying work had started despite decision-only scope. The warm native sample improved
handoff wording, but is not a full personality, recall or task-quality evaluation. No route is
accepted or selected solely from the stopwatch.

Before a live route change, evaluate the exact account/model/effort for relevant brief replies,
positive/negative/ambiguous handoff, continuation of A, unrelated B, quick C, precise steering,
missing auth/capacity and temporary context gaps. Require inherited original source, no internal
coordination narration, no needless approval and no action claim before admission. Workers stay
High. Then use real Telegram/Voice/Active Work and the owning Parallel Work acceptance cases.

## Recommendation and remaining integration

For a **documented quota-native** option, evaluate retained Opus 5 native sessions first. This is
not Direct and must not be relabelled. Existing native session ownership should be reused; no
second process manager is proposed. The subsequent local switch establishes retained CLI conversations on Telegram and browser Voice; see the separate channel receipt.

For **Direct**, official ChatGPT sign-in is the clearest tested plan-quota candidate. Its public
SDK grant works locally; xPerfect's current Direct account gate still needs integration. Saved
Anthropic Direct remains an experimental compatibility option with its support caveat. Keep API
credits last; the tested API project cannot provide the same Sol model.

The inference matrix alone does not prove target handoff or restart acceptance. Later actual channel evidence records the integrated local Native coordinator separately. It does not turn the inference-only matrix into channel, hardware or shipped-release acceptance.

## Reproduce and maintain

1. Use an isolated private directory, intended account, exact requested model and explicit settings.
   Check funding, permissions and required consent before any new account route. No paid fallback.
2. Capture the authorized authority/history at the real adapter boundary. Retain roles and bytes,
   source bindings, current Feelings and allowed capabilities. Scan for credentials before replay.
3. Keep cold, warm, Direct and alternate-model probes separate. Save original failures, provider
   identity, effective model, caches, output and clocks privately. Never rewrite results to pass.
4. Run the affected positive, negative and adjacent cases. Use channel acceptance only after actual
   product wiring; model-only decisions cannot close admission, delivery or recovery cases.
5. Publish sanitized samples/aggregates only. Run `python3 qa/parallel-work/benchmarks/render.py`;
   verify metric agreement, the source SVG, links, both themes, mobile, keyboard and reload.
   The renderer owns the guide's shared diagram and inference tables. The current alignment
   assessment is separately authored; compare its displayed inference and channel metrics with
   `results.json` and `native-channel-samples.json` rather than overwriting its dated evidence.

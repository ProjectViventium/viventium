1. Selected: warm native Claude Code, exact Opus 5 Low, plan quota, for Main and Voice. Workers stay High. Keep credits last. Native is distinct from Direct.
2. Reuse the current minimal inherited-source handoff as durable admission to the existing native
   background coordinator. Prove one manager and no serial planning on the speaking path.
3. Preserve original sources through coordinator dispatch and context readers; remove required
   paraphrase opportunities, not intelligence or native safety/capacity checks.
4. Join the existing durable result/receipt path to the same speaking Queen; preserve High Workers,
   exact controls, scheduled continuation, failure truth and private Life context.
5. Run the real acceptance journey before changing defaults or claiming a shipped repair.

No keyword/regex intent router, hardcoded provider rubric, second cognitive memory, new scheduler
or custom browser/audio runtime is proposed. Models choose actions; runtime preserves typed
identity, authorization, durable admission, effects, ordering and receipts.

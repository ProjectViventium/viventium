## Problems found and corrected during QA

1. The Sources mobile page could exceed the viewport width; the layout now has zero horizontal
   overflow at 390 pixels.
2. The setup modal footer could fall below the mobile viewport; its header and footer are now sticky
   and the primary action remains reachable.
3. The architecture's portable JSON initially preserved box edits but not the complete section and
   connection topology; schema `1.2` now exports and imports sections, nodes, dimensions, and edges.
4. The All-sources primary action initially opened an inbox-specific flow; it now opens the general
   source catalog, while Inboxes retains the minimal inbox flow.
5. One YAML fixture contained an accidental patch marker and the schema route lacked its intended
   guide; both were corrected before acceptance.
6. CRM and How-to-Write were implicit in parent folders; explicit routed examples were added so the
   fixture demonstrates the requested canonical pattern rather than merely naming it.
7. The first architecture draft overstated current GlassHive folder access. The accepted proposal
   now starts host-native, waits for the worker-returned workspace, preserves current
   `project-definition.md`, `glasshive-run/evidence.json`, and `FINAL REPORT:` surfaces, and treats
   Docker mounting/callback changes as gated contract work.
8. Conversation summaries initially blurred actual conversations, transcripts, and ambient
   evidence. Those are now separate Life projections with independent authority and routing rules.
9. Sleep Growth initially looked like a new sequential nightly orchestrator. It is now a read-only
   join over existing independent jobs and run IDs; private receipts stay in `99_System/night-runs/`,
   briefs are pull-only by default, and saved-memory writes remain off by default.
10. The cortex description initially invented agent-agent semantics as current behavior. Current
    Activation Detection and asynchronous Phase A/B semantics are restored; sealed agent exchange
    is clearly a new V0.5 hypothesis requiring a contract amendment and parity evidence.
11. The AI-account copy initially implied xAI could stand alone. The proposal now keeps OpenAI or
    Anthropic as the required current foundation, treats xAI as optional, and describes Groq as the
    fast activation route with approved fallbacks.
12. Mission deltas, questions, promotions, insights, evidence, and source manifests were prose-only.
    Typed draft schemas, callback/checkpoint mapping, independent evidence authorship, and a
    promotion policy now make the proposed contract inspectable.
13. The first editor could not resize boxes or edit connection topology, and the SVG shortened some
    labels. The accepted studio edits box size and every connection property; schema `1.2` preserves
    that state and the checked standalone SVG contains the complete text.
14. A real-browser pass of the standalone SVG exposed invisible editor hit targets as black filled
    shapes outside the studio stylesheet. Exported SVG CSS now keeps those paths transparent; the
    corrected standalone browser screenshot shows the complete architecture without artifacts.

## Independent review

The first external review-only architecture pass judged the strategy conditionally strong but found
critical truth gaps in GlassHive runtime compatibility, cortex semantics, and memory boundaries,
plus high-risk gaps in foundation requirements, nightly orchestration, evidence ownership, and
portable editing. Each finding was checked against the numbered Viventium requirements and either
corrected or explicitly gated as future contract work.

A fresh review-only remediation audit then read the current files directly. Its verdict was
**STRONG**, with **no critical or high findings remaining**, and **safe to present as a V0.5
design/prototype**. Its only requested correction was to replace the stale workspace path and
pending-review marker in this report; both are corrected above.

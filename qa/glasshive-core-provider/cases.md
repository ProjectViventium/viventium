## Acceptance Rules

- Every applicable row is `PASS`, `FAIL`, `PARTIAL`, or `BLOCKED` in a dated report.
- A required real user path cannot be replaced by a mock, source review, unit test, DB row, or another
  model's review.
- Forbidden results: wrapper LLM authorship, silent unconfigured OpenAI fallback, duplicate or overlapping harness
  run/reply, GlassHive as Phase A/Voice LLM, any fallback after native authoring evidence or an
  external/unknown effect, blocking fallback merely because a server-declared graph/read-only tool ran,
  silently enabling the provider-internal fallback instead of Agent Builder `fallback_llm_*`,
  conflating the two fallback layers, provider-internal switching on unstructured error text or after
  authoring/tool/file activity, specialist Feelings injection, runtime files in LIFE,
  hidden chain-of-thought, or private data in committed evidence.

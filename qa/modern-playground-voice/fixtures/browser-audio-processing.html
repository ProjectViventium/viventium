Phone sound check

Each test plays the same quiet six-second tone. Listen during the middle of the tone. Tests 1–3 compare microphone processing. Tests 4–5 also check routing and microphone release. Nothing is recorded or uploaded.

Start in a fresh browser session. Run 1, 2, 3, then 1 again. Some phone browsers keep audio-processing state even after a reload; mixed results need a full browser restart, not just a page reload. Keep the same volume and grip. Note crackle, loudness and speaker or earpiece for each test. Echo control off is a diagnostic, not a call setting. This quiet tone cannot rule out distortion that occurs only during louder speech.

Ready. Start at a comfortable speaker volume.

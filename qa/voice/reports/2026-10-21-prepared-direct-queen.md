## Independent output-path review

Opus identified a further issue, confirmed against the Direct runner and three saved live reply
pairs: each response contained ordinary prose and then the same prose in the structured output
function, with one added voice-emotion tag. The launch also had an earlier acknowledgement before
tool acceptance. Untyped prose is deliberately ineligible for speech under the current delivery
contract. In these observed responses, final function arguments arrived together; HTTP streaming
did not establish incremental delivery of the public reply.

The launch's provider-to-speakable interval was 15.05 seconds; arithmetic was 7.59 seconds; the
completed-title follow-up was 3.65 seconds. Their mixed mean is not isolated inference. A repair
should use the existing typed output contract to produce the reply once and stream its content,
while preserving silent/internal controls and truthful action receipts. Native structured output
with ordinary tools remains a candidate requiring exact-model evaluation, not a delivered fix.
Do not speak arbitrary raw prose to make the first-audio metric shorter.

The review also rejected using workspace bootstrap files for shared conversation history: host
workers can run inside the user's normal workspace. Reuse the scoped context-source owner without
materializing private conversation history as ordinary workspace files. A current task selection
must remain distinct from historical requests so that old actions are not executed again.

## Coordination-only Direct Queen repair (later same-day candidate)

This section supersedes the earlier statement that prepared context inheritance is absent.
It does not supersede the recorded failures or turn a diagnostic into user acceptance.

The canonical Voice default is now xPerfect Direct xAI Grok 4.7 Low with
`orchestration.tool_mode: coordination`. The only work tools exposed to this Direct mode are
`hand_off_to` and `list_workers`; typed reply output remains separate. Full/native profiles keep
their action tools. Schedules, search, files and diagnostics execute through configured workers.
Worker and fallback settings remain independent. Low is not disabled reasoning: the exact
Grok 4.7 API rejects `none`; no unsupported setting or different model was substituted.

Handoff selects original current input by source identity; it does not require a model-written
brief. The existing trusted broker resource cache retains the exact authorized conversation,
separate from capability descriptors. Its reference is owner/conversation/digest-bound. Existing
launch signatures bind the context digest; public bootstrap fields cannot forge it. The existing
native clean-room allowlist now preserves the snapshot through admission and storage. Native
readers prioritize current and recent material inline and retain full paged access. Queue,
Message, Steer and Retry refresh context through existing signed action receipts and continuation
state, without mutating the original worker bootstrap or adding an orchestration service.

An initial real call exposed two defects despite focused tests: a worker did not receive an
earlier spoken check word, and callback synthesis threw on absent trusted metadata. Both causes
were reproduced and repaired at their existing owners. The first test is retained as failed;

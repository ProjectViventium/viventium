## What Was Actually Run

- Real Chromium pointer and keyboard interaction through Playwright CLI.
- Desktop visual inspection at 1440×1000 and 1024×900.
- Tablet/mobile inspection at 768×900, 390×844, and 320×700.
- Cross-tab and refresh persistence for connection receipt, presence policy, Feeling/Nature state,
  voice provider, selected automation, and Anywhere Access. The email address itself did not persist.
- Email invalid/valid input, all three connection-route families, scope, destination, and simulated
  receipt behavior. No real authentication occurred.
- Automation run → pause → wait beyond completion timer, resume → complete, run → cancel → wait,
  and refresh interruption handling.
- Native Anywhere dialog initial focus, Escape close, focus return, and simulated enable persistence.
- System light/dark rendering, keyboard skip link, browser console, script syntax, local asset loads,
  and public-safety/static-source scans.

## Defects Found And Corrected

- Paused/cancelled automation timers could falsely complete behind the visible state. Timers are now
  cleared, completion is status-guarded, resume is truthful, and refresh demotes interrupted runs to
  an inspectable waiting state.
- The 1024 CHARACTER/AUTOMATIONS responsive layout could overlap essential secondary content. Both
  now remain full three-column instruments at that width and stack below the tablet breakpoint.
- An animated view created the wrong containing block for the mobile email sheet, placing it above
  the visible viewport. Mobile view animation is disabled and the sheet is viewport-bound.
- The off-canvas mobile email sheet contributed hidden horizontal overflow. Mobile horizontal
  overflow is contained and acceptance widths match the viewport exactly.
- Mobile tab changes retained the previous page's scroll position. They now return to the new
  destination's top.
- The email sheet initially covered the persistent presence controls on mobile. Its bottom inset now
  preserves the living dock.
- Initial page setup stole keyboard focus from the skip link. Initialization no longer moves focus;
  explicit destination changes still focus the main surface.
- The MIND seed data could be mistaken for a live runtime in isolation. A subtle persistent
  `DESIGN PROTOTYPE` marker now labels it.

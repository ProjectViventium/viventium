# Viventium-Health parent integration QA

This folder owns public-safe acceptance for the boundary between Viventium Core and the independently
versioned Viventium-Health component. Provider research, connector behavior, raw archive truth, and
owner-safe WHOOP evidence remain in the component repository.

Parent QA covers compiled/direct MCP parity, exact component pins, read-only main-agent bindings,
protected live-agent synchronization, real browser behavior, restart persistence, and the guarantee
that no health payload or credential enters public evidence or saved memory. Deliberately retrieved
bounded chunks may be retained in ordinary private conversation/tool-result history; the parent must
not create a separate health database or canonical copy.

The current status is tracked in [cases.md](cases.md). Dated reports must contain only public-safe
counts, status classes, tool names, and integrity results.

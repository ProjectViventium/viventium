# Insights

This is the visible home for governed overnight and deliberate thought. Existing runtime stores may
retain the authoritative artifact and run state; Life holds accepted artifacts, projections, and
durable references.

| Folder | Content |
|---|---|
| `Morning_Briefs/` | Pull-only “what changed and what matters” wake views by default; proactive delivery requires opt-in |
| `Patterns/` | Repeated relationships or behavior across evidence |
| `Ideas/` | Possibilities worth exploring, not decisions |
| `Conclusions/` | Evidence-backed interpretations with confidence and falsifiers |
| `Risks/` | Threats, blind spots, and opportunity costs |
| `Opportunities/` | Time-sensitive or strategic openings |
| `Open_Questions/` | Important unknowns and the evidence needed |
| `Workers/` | Approved night-worker definitions and scopes |

Every insight states sources, generated time, confidence, freshness/staleness, what would make it
wrong, blind spots, opportunity costs, and when it should surface. Generated insight is not saved
memory or canonical truth by default. Private, serializer-redacted run manifests and receipts live
under `99_System/night-runs/`; this folder contains only eligible human-facing projections.

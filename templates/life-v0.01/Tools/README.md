# Tools

Human-readable inventory of tool capabilities available to Viventium and its agent hosts.

Each entry should state:

- logical tool ID and human purpose;
- owning host or service;
- read/write/destructive scope;
- auth mode without secrets;
- permission and confirmation behavior;
- health and last verified time;
- supported surfaces and fallback;
- source documentation.

Do not confuse a configured tool with a verified healthy tool.

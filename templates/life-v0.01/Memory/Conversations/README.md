# Conversation Memory

Store detailed, timestamped, source-linked episodic summaries here:

`YYYY/MM/YYYY-MM-DDTHHMMSSZ--<source>--<slug>.summary.md`

Use [the summary template](_template/CONVERSATION_SUMMARY.md). The original conversation remains in
its authoritative host. A summary is not a verbatim transcript and must be updated or superseded
when corrections arrive.

Meeting, call, and imported transcript evidence belongs in `Memory/Transcripts/`. Listen-only and
ambient evidence belongs in `Memory/Ambient/`; neither may be presented as a chat conversation.

# Memory

Human-browsable continuity projections. Keep these distinct from the product's compact saved-memory
store and from one another:

- stable accepted facts and preferences;
- episodic actual-conversation summaries under `Conversations/`;
- meeting, call, and imported transcript evidence under `Transcripts/`;
- consented listen-only and ambient evidence under `Ambient/`;
- generated insights;
- retrieval indexes.

Each has different authority, correction, retention, and forgetting behavior.

# Life System Contracts

Machine-readable and operational support for the human-browsable Life tree.

- `sources.yaml`: private source registry created from the example.
- `schemas/`: portable contracts for summaries, missions, insights, and receipts.
- `provenance/`: source and transformation lineage.
- `sync/`: incremental checkpoints, health, and full-audit receipts.
- `proposals/`: governed changes awaiting review or application.
- `receipts/`: source collection and canonical promotion receipts.
- `indexes/`: rebuildable search and navigation indexes.

This folder contains no credentials and no irreplaceable hidden database.

# Calendar

Keep source-linked event projections, availability views, commitments, and cross-calendar summaries
here. External calendars remain authoritative. Preserve source, calendar identity, event identity,
time zone, freshness, and last-sync state; never store credentials.

Calendar evidence may inform `Plans/`, `Projects/`, `People/`, and `Insights/`, but those derived
views link back here or to the authoritative provider instead of becoming unsourced duplicates.

# Viventium LIFE v0.01

This is the public-safe additive bootstrap for each local user's canonical Viventium LIFE folder.
It provides a stable working context for harness-backed Viventium agents without activating the
broader V0.5 night-worker, Brain Pack, or Insights automation thesis.

## Start here

1. Read `AGENTS.md`; it is canonical for Codex, Claude Code, and other harnesses in this tree.
2. Personalize `CURRENT.md` into a short map of what is true and active now.
3. Put durable material in the closest relevant area. Keep original authority in the source system
   and store links, summaries, or accepted artifacts here as appropriate.

## Folder map

| Folder | Purpose |
|---|---|
| `Self/` | Identity, values, preferences, boundaries, methods, and history |
| `People/` | Relationship context and personal CRM views |
| `Health/`, `Legal/`, `Finance/`, `Home/`, `Learning/` | Domain evidence, goals, decisions, and plans |
| `Projects/` | Active outcome-oriented work |
| `Plans/` | Cross-project commitments, routines, and scenarios |
| `Communications/`, `Calendar/`, `Social/` | Source-linked communication and activity views |
| `Places/`, `Events/`, `Media/` | Location, lived-event, photo, and video context |
| `Memory/` | Human-browsable episodic summaries and source-linked transcript/ambient views |
| `Insights/` | User-facing ideas, patterns, risks, opportunities, and open questions |
| `Skills/`, `Tools/`, `Services/`, `Sources/` | Reusable methods and capability/source inventories |
| `Views/` | Generated dashboards and indexes |
| `Decisions_and_History/` | Decisions, rationale, corrections, and supersession |
| `Workspaces/` | User-directed working areas |
| `Archive/` | Deliberately inactive retained material |
| `99_System/` | Private LIFE bookkeeping, schemas, provenance, and indexes |

## Authority and privacy

LIFE is canonical for human-authored or explicitly accepted LIFE artifacts. Original chats,
transcripts, calendars, email, and other connected systems retain authority for their own records.
LIFE may organize and summarize those sources; it must not silently rewrite them or pretend a
derived summary is the original.

Never store credentials here. Keep runtime logs, harness transcripts, execution metadata, and
authentication state in Viventium's private Application Support state.

## Bootstrap behavior

Installation creates missing directories and files under `~/Documents/Viventium/Life`, never
overwrites personalized content, and records the template version outside LIFE. The bootstrap
excludes `CLAUDE.md`, `CODEX.md`, `.git`, mission scaffolding, receipts, and runtime logs.
